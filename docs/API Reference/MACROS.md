# Global project macros

<a name="ax_um"></a>
## AX_UM
---
This macro indicates user mode build type.
It cannot be paired with [AX_KM](#ax_km)

<a name="ax_km"/></a>
## AX_KM
---
This macro indicates kernel mode build type.
It cannot be paired with [AX_UM](#ax_um)

<a name="ax_linux"/></a>
## AX_LINUX
---
This macro indicates build for linux.
It cannot be paired with [AX_LINUX](#ax_linux)

<a name="ax_win64"/></a>
## AX_WIN64
---
This macro indicates build for windows.
It cannot be paired with [AX_WIN64](#ax_win64)
